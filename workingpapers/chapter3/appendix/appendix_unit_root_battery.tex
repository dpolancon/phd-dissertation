\section[Integration Order Diagnostics and Unit Root Battery]{Integration Order Diagnostics and Complete\\Unit Root Battery (Chile, 1920--2010)}
\label{app:unit_root_battery}

This appendix documents the econometric unit-root analysis evaluating the stochastic properties and integration order of 19 candidate macroeconomic and balance-of-payments variables for Chile over the secular horizon (1920--2010, $T=91$). Using the \texttt{urca} package in \textsf{R}, I implement a comprehensive four-test battery:
\begin{enumerate}[leftmargin=2em]
	\item \textbf{Augmented Dickey-Fuller (ADF)} test with drift (\texttt{ur.df}, $5\%$ critical value: $-2.89$);
	\item \textbf{Elliott-Rothenberg-Stock (DF-GLS)} test with constant (\texttt{ur.ers}, $5\%$ critical value: $-1.94$);
	\item \textbf{Kwiatkowski-Phillips-Schmidt-Shin (KPSS)} test for level stationarity around a constant (\texttt{ur.kpss}, $5\%$ critical value: $0.463$);
	\item \textbf{Zivot-Andrews (ZA)} test allowing for a single endogenous structural break in both intercept and trend (\texttt{ur.za}, $5\%$ critical value: $-5.08$).
\end{enumerate}

Table~\ref{tab:urca_results_full} reports the empirical test statistics, endogenous break dates, and formal stationarity classifications. The candidate series fall into two distinct operational categories:
\begin{itemize}[leftmargin=2em]
	\item \textbf{$I(0)$ Pure Stationary:} Series that reject the unit-root null in standard ADF/DF-GLS tests and fail to reject the stationary null in KPSS tests without requiring structural break corrections (e.g., base money growth $g_{M0}$, narrow money growth $g_{M1}$, CPI inflation $\pi_t$, USD reserve growth $g_{IR}$, and fiscal deficit as \% of GDP).
	\item \textbf{$I(0)$ Conditional on an Endogenous Structural Break:} Series where secular institutional realignments (such as the 1934 post-Depression agricultural collapse, the 1944 wartime shift, the 1958 Klein-Saks stabilization, or the 1981 debt crisis) generate spurious unit-root non-rejection under standard linear tests, but decisively reject the unit-root null once endogenous break dynamics are accommodated.
\end{itemize}
